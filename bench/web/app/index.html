Reading the numbers

Comparable Lean bytes. Native Lean and VIR use the same level and must emit exactly the same stream. FIR joins this exact check at level 0.

Independent codec settings. CompressionStream has no level API; fflate caps its knob at 9. Their level labels are not quality equivalence claims.

Timing boundaries. Browser calls run in dedicated workers. Native samples are measured inside one Lean process; validation happens afterward.

Supported VIR only. VIR persists nullary constants for one loaded package set. The superseded per-call-cache runtime is not part of the dataset.

FIR scope. FIR's resident ByteArray stored compressor is executable and zero-import. Level 1/full raw DEFLATE remain gated on final-capture support.
